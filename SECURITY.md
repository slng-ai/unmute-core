# Security

## Report a problem

Report a security problem privately on GitHub: open the [Security tab](https://github.com/slng-ai/unmute-core/security) and click "Report a vulnerability".

Do not open a public issue for a security problem.

Include:

1. The unmute-core version and the framework (LiveKit or Pipecat) with its version.
2. What an attacker can do, and the steps to reproduce it.
3. A fix idea, if you have one.

We answer within 5 working days.

## Supported versions

Only the newest release gets security fixes. Before 1.0, a fix ships as a new patch version of the newest minor version, like `0.14.1`.
